# 🎮 파이썬 퀴즈 게임 프로젝트

이 프로그램은 파이썬으로 만든 간단한 퀴즈 게임입니다. 퀴즈를 풀고, 직접 문제를 추가할 수도 있습니다.

## 💡 퀴즈 주제: 상식 퀴즈 (원하는 주제로 수정하세요)
- **선정 이유**: 누구나 쉽게 참여할 수 있고, 재미있게 지식을 쌓을 수 있어서 선정했습니다.

1. 터미널(검은 창)에 아래 명령어를 입력합니다.

## 🛠 주요 기능
- **퀴즈 풀기**: 저장된 문제를 풀고 점수를 얻습니다.
- **퀴즈 추가**: 새로운 문제를 직접 등록합니다.
- **목록 보기**: 현재 등록된 문제들을 확인합니다.
- **최고 점수**: 나의 역대 최고 점수를 확인합니다.

## 📁 파일 구성
- `main.py`: 게임 실행 코드
- `state.json`: 퀴즈와 점수가 저장되는 파일
- `README.md`: 프로젝트 설명서

## 💾 데이터 저장 (state.json)
- `quizzes`: 문제 리스트
- `best_score`: 최고 점수
