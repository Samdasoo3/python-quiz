# 🐍 파이썬 퀴즈 게임 (Python Quiz Game)

파이썬 클래스와 JSON 데이터 처리를 학습하기 위한 콘솔 기반 퀴즈 프로젝트입니다.

## ✨ 주요 기능
- **퀴즈 풀기**: 저장된 문제를 풀고 점수를 확인합니다.
- **최고 점수 기록**: `state.json`을 통해 역대 최고 점수를 저장하고 불러옵니다.
- **문제 관리**: 퀴즈를 추가, 목록 확인, 삭제할 수 있습니다. (CRUD)
- **데이터 영속성**: 모든 데이터는 JSON 파일에 저장되어 재실행 시에도 유지됩니다.
- **예외 처리**: 빈 파일 로드 및 잘못된 입력에 대한 예외 처리가 적용되어 있습니다.

## 🛠 기술 스택
- **Language**: Python 3.x
- **Data**: JSON
- **Version Control**: Git / GitHub
